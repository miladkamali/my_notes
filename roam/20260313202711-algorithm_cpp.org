* algorithm
** search/inspect algorithm
*** all_of
Check if every item matches a rule
std::all_of(v.begin(), v.end(), [](int x){ return x > 0; });
*** any_of
Check if at least one item matches
std::any_of(v.begin(), v.end(), [](int x){ return x == 0; });
*** none_of
Check if no item matches
std::none_of(v.begin(), v.end(), [](int x){ return x < 0; });
*** for_each
Run an action for every item
std::for_each(v.begin(), v.end(), [](int& x){ x *= 2; });
*** for_each_n
Run an action on the first n items
std::for_each_n(v.begin(), 3, [](int& x){ x += 10; });
*** count
Count exact matches
std::count(v.begin(), v.end(), 5);
*** count_if
Count items matching a rule
std::count_if(v.begin(), v.end(), [](int x){ return x % 2 == 0; });
*** mismatch
Find first place where two ranges differ
auto p = std::mismatch(a.begin(), a.end(), b.begin());
*** equal
Check if two ranges are equal
std::equal(a.begin(), a.end(), b.begin());
*** find
Find a specific value
auto it = std::find(v.begin(), v.end(), 42);
*** find_if
Find first item matching a rule
auto it = std::find_if(v.begin(), v.end(), [](int x){ return x > 10; });
*** find_if_not
Find first item not matching a rule
auto it = std::find_if_not(v.begin(), v.end(), [](int x){ return x > 0; });
*** adjacent_find
Find equal neighbors
auto it = std::adjacent_find(v.begin(), v.end());
*** search
Find a subsequence inside another
auto it = std::search(text.begin(), text.end(), pat.begin(), pat.end());
*** search_n
Find n repeated values in a row
auto it = std::search_n(v.begin(), v.end(), 3, 0);
*** find_end
Find the last occurrence of a subsequence
auto it = std::find_end(text.begin(), text.end(), pat.begin(), pat.end());
*** find_first_of
Find first element that appears in another set
auto it = std::find_first_of(v.begin(), v.end(), needles.begin(), needles.end());

* numeric
** std::accumulate

What it does: folds a range into one value, usually a sum.
Use when: you want one final result from many elements.

#include <numeric>
#include <vector>

std::vector<int> v{1,2,3,4};
int sum = std::accumulate(v.begin(), v.end(), 0);   // 10

With custom operation:

int product = std::accumulate(v.begin(), v.end(), 1,
    [](int a, int b) { return a * b; });            // 24

* std::ranges algorithm
2) The newer std::ranges algorithm forms

What changes with ranges?

The big idea is not “new behavior”, but new calling style:

Classic form:

std::sort(v.begin(), v.end());

Ranges form:

std::ranges::sort(v);

Ranges algorithms are mostly the same algorithm families as the classic ones, but they accept a whole range and are constrained by concepts.  ￼

** 2M) A few useful std::ranges helpers that are not algorithms

These are often confused with algorithms, so it helps to separate them:
	•	std::ranges::begin, end, size, empty, data, distance, next, prev
	•	std::views::filter, transform, take, drop, split, keys, values

These are part of the ranges ecosystem, but they are helper functions or views/adaptors, not the algorithm family itself.  ￼
