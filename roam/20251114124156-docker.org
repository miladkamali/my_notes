Based on the container info you provided, here is the sequence of commands to get that image into the new registry.


### Why this works better
1. **Explicit Targeting:** By providing the full name `registry.uid.ir/uid/liveness-detection:master-v1.0.1`, you tell Docker exactly which layer stack to grab.
2. **Tag Matching:** It ensures the version string (`master-v1.0.1`) carries over correctly to the new registry.

### If you still want to use the ID
If you prefer using the ID, you must specify the tag explicitly so Docker doesn't append `:latest`. However, using the full name (above) is the standard "best practice" for production moves.

**Alternative using ID:**
