** Send
data is Send if it can be sent between threads safely, This means No Unsafe Mutable.
if all the fields in the struct is Send compatible, the entire struct is promoted to be Send compatible
#+begin_src rust
  pub unsafe auto trait Send{
  }
#+end_src
** Sync
#+begin_src rust
  pub unsafe auto trait Sync {
  }
#+end_src
Data is Sync if it can be shared between threads safely. It promises that data
is mutable safely with things like Mutexes and atomic

if all the fields in a struct are Sync compatible, the Struct is promoted to be Sync compatible.
